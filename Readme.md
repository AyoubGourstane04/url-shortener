
# URL Shortener

This repository contains a full-stack URL shortening application split into two subprojects:

- `url-shortner-backend/`: A Spring Boot backend service using Java, PostgreSQL, Redis, and a Python QR code generator.
- `url-shortner-frontend/`: A React + TypeScript + Vite frontend that interacts with the backend APIs.

## Project Overview

This project provides a web application for shortening URLs, redirecting short codes to their original links, and generating downloadable QR codes for shortened links. The backend exposes REST APIs, while the frontend provides a responsive user interface with clipboard and QR code sharing support.

## Architecture

The application is separated into two clearly defined layers:

- Backend: Spring Boot application with persistence and caching.
- Frontend: React application using Vite and TypeScript.

The backend stores URL records in PostgreSQL, caches queries in Redis, and uses a Python utility to generate QR codes. The frontend calls the backend API from `http://localhost:8080/api/v1/`.

## Backend

### Tech Stack

- Java 21
- Spring Boot 4.1
- Spring Web MVC
- Spring Data JPA
- PostgreSQL
- Spring Data Redis
- AspectJ / AOP for execution logging
- Python QR code generation script

### Key Features

- Shorten a long URL and return a short code.
- Redirect a short code to the original URL.
- Generate QR codes for shortened URLs.
- List all stored URL entries.
- Clear all stored URLs.
- Redis caching for shorten and redirect operations.

### API Endpoints

The backend controller is mounted at `/api/v1/`.

- `POST /api/v1/shorten`

  - Accepts a JSON body with `{ "url": "https://example.com" }`.
  - Returns a `ShortenResponseDTO` containing `originalUrl`, `shortCode`, and `shortUrl`.
- `GET /api/v1/{shortCode}`

  - Redirects to the original URL associated with the short code.
  - Returns `302 Found` with a `Location` header when the short code exists.
  - Returns `404 Not Found` when the short code does not exist.
- `GET /api/v1/qr`

  - Accepts a JSON body with `{ "url": "https://example.com" }`.
  - Creates or reuses a shortened URL and attempts to generate a QR code image.
  - Returns a `GenerateQrCodeResponseDTO` containing `url`, `shortUrl`, and `qrCodePath` when available.
- `GET /api/v1/`

  - Returns a list of all `UrlInfo` records.
- `DELETE /api/v1/truncate`

  - Deletes all rows from the `urls` table and restarts the table identity.
  - Returns `204 No Content`.

### Data Model

The backend stores URL metadata in the `UrlInfo` entity:

- `id` — UUID primary key generated by JPA.
- `url` — original long URL.
- `shortCode` — shortened identifier for redirect.
- `createdAt` — timestamp when the record was created.

Short codes are generated by encoding the `UUID` value with a Base62 algorithm and truncating the result to the first 7 characters.

### Caching

The backend configures Redis caching via `RedisConfig`.

- Cache names:
  - `urls` — used when shortening URLs.
  - `redirects` — used when resolving short codes.
- TTLs:
  - `urls`: 10 minutes
  - `redirects`: 60 minutes

The `shorten` and `getURL` service methods are annotated with `@Cacheable`, and `truncateAllURLs` evicts the URL cache with `@CacheEvict`.

### QR Code Generation

QR code generation is handled by a Python script at `url-shortner-backend/src/main/resources/python/generate_qr_code.py`.

- The Java service calls `CommandRunner.runPythonScript(shortUrl)`.
- The script uses the `qrcode` Python library to render a PNG file.
- Generated PNGs are placed under the backend QR code resources folder.

### Configuration

Application configuration is located in `url-shortner-backend/src/main/resources/application.properties`.

The backend reads PostgreSQL and Redis connection settings from environment variables:

- `DB_NAME`
- `POSTGRES_USERNAME`
- `POSTGRES_PASSWORD`

It also uses:

- `spring.data.redis.host=localhost`
- `spring.data.redis.port=6379`
- `spring.cache.type=redis`

### Running the Backend

From the `url-shortner-backend/` directory, use Maven:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
.\mvnw.cmd spring-boot:run
```

Before running the backend, ensure PostgreSQL and Redis are available and the required environment variables are set.

## Frontend

### Tech Stack

- React 19
- TypeScript 6
- Vite
- Tailwind CSS
- Lucide React
- qrcode.react
- Oxlint for linting

### Key Features

- Two tabbed UI flows:
  - Shorten a URL
  - Generate a QR code
- Clipboard copy for shortened URLs
- Download and share QR codes from the browser
- Responsive, card-based design

### Important Components

- `src/sections/InputCard.tsx`

  - Main UI for user input and tab navigation.
  - Handles URL shortening and QR generation workflows.
- `src/components/ResponseURL.tsx`

  - Displays the shortened URL.
  - Copies the URL to the clipboard with a temporary confirmation state.
- `src/components/ResponseQR.tsx`

  - Renders a QR code using `QRCodeCanvas`.
  - Supports download and native browser sharing when available.
- `src/api/apiClient.ts`

  - Centralizes backend calls to `http://localhost:8080/api/v1/`.
- `src/api/urlApi.ts`

  - Provides `shortenUrl()` to call the backend shorten endpoint.
- `src/types/projTypes.ts`

  - Defines TypeScript types used by the frontend.

### Running the Frontend

From the `url-shortner-frontend/` directory:

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```

The frontend expects the backend API to be reachable at `http://localhost:8080/api/v1/`.

## Docker Support

The backend includes `docker-compose.yaml` for local PostgreSQL and Redis development.

- `url-shortner-db`: PostgreSQL 16
- `redis`: Redis 7

Start the containers with:

```bash
docker compose up
```

Ensure the environment variables used by Docker Compose are set before launching the services.

## Directory Structure

- `url-shortner-backend/`
  - `pom.xml` — backend Maven project configuration.
  - `docker-compose.yaml` — local PostgreSQL and Redis setup.
  - `src/main/java/com/ayoub/url_shortener/` — backend source code.
  - `src/main/resources/` — backend configuration, Python script, and QR assets.
- `url-shortner-frontend/`
  - `package.json` — frontend project configuration.
  - `src/` — React application source code.
  - `public/` — static public assets.

## Notes

- The backend currently uses a hardcoded host URL constant (`http://localhost:8080/api/v1/`) for generated short links.
- QR code generation relies on a Python script and the `qrcode` library.
- The frontend UI is designed for local development and assumes the backend is available on `localhost:8080`.
- The backend `GET /api/v1/qr` endpoint accepts a JSON request body to trigger QR code creation.
